# Three complete, bounded research examples

Run `uv run python examples/run_examples.py --out .cache/example-studies` from the repository root. Choose an unused output directory. Each example saves actual materials, findings, a draft, review, revision and a read-only workspace.

| Example | What it demonstrates |
| --- | --- |
| Computational | A deterministic synthetic comparison with recorded source/results and an explicit negative result |
| Interpretive | Close reading of public-domain constitutional wording, rival readings and context limits |
| Formal | An induction proof with assumptions, a proof audit and numerical checks labeled as illustrations |

These are teaching/acceptance examples, not novel discoveries, expert-certified scholarship or human participant research. Researcher-confirmation fields remain false: a script cannot provide a human's final scientific judgment.

The more extensive [drift study](drift-study/README.md) remains separately runnable and tests temporal splitting, matched budgets and uncertainty over independent simulations.
