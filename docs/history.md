# Developer history

The current plugin installs and runs Latest only. Historical implementations are available for reading, checkout, fork and independent research through [Tags](https://github.com/HaoYangJin/Big-Research/tags), [Releases](https://github.com/HaoYangJin/Big-Research/releases) and [Commit History](https://github.com/HaoYangJin/Big-Research/commits/main/).

Historical release guides and validation notes remain in their original tags. They are not current installation instructions. Old executors, old Skill entries and old command aliases are not included in the current package. The current data importer reads known historical formats without loading or invoking historical code.
