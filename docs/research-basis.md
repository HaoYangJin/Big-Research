# Research basis and acknowledgments

Primary materials were inspected on 2026-10-16/17. We independently implement the following ideas; references do not imply endorsement, bundled code or reproduced benchmark results.

| Source | Design use |
| --- | --- |
| [nature-skills](https://github.com/Yuan1z0825/nature-skills) | Progressive loading, figure evidence and rendered inspection |
| [academic-research-skills](https://github.com/Imbad0202/academic-research-skills) | Exploratory dialogue, claim/citation checks and revision tracing; no CC-BY-NC implementation files copied |
| [scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills) | Method/domain modularity and applicability boundaries |
| [AutoResearchClaw](https://github.com/aiming-lab/AutoResearchClaw) | Checkpoints, alternatives, failure recovery and resources |
| [AI-Research-SKILLs](https://github.com/Orchestra-Research/AI-Research-SKILLs) | Focused capability composition and research engineering |
| [DeepMind Co-Scientist](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/) | Candidate generation, critique and iterative refinement |
| [Sakana AI Scientist](https://sakana.ai/ai-scientist/) | Inspectable experiment/writing loops; human leadership remains this project's purpose |
| [Anthropic Research](https://www.anthropic.com/engineering/multi-agent-research-system) | Dynamic investigation, source grounding and bounded coordination |
| [Stanford Agentic Reviewer](https://paperreview.ai/tech-overview) | Multi-specificity literature grounding and dimension-level feedback; no imported calibration |
| [Analemma official FARS report](https://www.linkedin.com/posts/analemmaai_ai-llm-research-activity-7431589315215966208-NQBz) | Inspectable intermediate artifacts, run identities, resources and assessment limits |
| [ICLR 2026](https://iclr.cc/Conferences/2026/ReviewerGuide) and [NeurIPS 2026](https://neurips.cc/Conferences/2026/ReviewerGuidelines) | Venue and contribution-sensitive review |
| [APA JARS](https://apastyle.apa.org/jars) and [EQUATOR](https://www.equator-network.org/library/) | Reporting profiles matched to study design, separate from validity assessment |
| [ACM SIGSIM artifact guidance](https://sigsim.acm.org/conf/pads/2022/blog/artifact-evaluation/) | Artifact consistency, completeness, exercise and reuse |
| [Public Humanities reviewer instructions](https://www.cambridge.org/core/journals/public-humanities/information/peer-review-information/instructions-for-peer-reviewers) | Context-sensitive humanities feedback; a bounded adaptation, not all humanities' official standard |

Stanford reports AI/human Spearman 0.42 versus human/human 0.41 in its ICLR-2025 setup (150 training/147 test submissions). This is not a cross-disciplinary correctness guarantee or validation of this plugin. We adopt no fitted score weights. Analemma's original FARS introduction timed out; we do not claim to have verified its internal architecture.

Bundled standards are short original mappings. For a full formal audit, retrieve the current official form/checklist, record version and item-level evidence, and comply with its AI/confidentiality policies. Public research systems are not descriptions of complete proprietary lab workflows.
