# Big Research v2.1.0

Big Research becomes a human-led research workspace: start with a question, choose methods that fit it, preserve the evidence, and revise with constructive feedback.

The release replaces the fixed nine-stage executor with an editable task graph, seven composable skills, method modules, a shared local CLI/MCP core and optional interactive views. Layered reviews support multiple disciplines without an uncalibrated universal score. Known v1 project data can be imported into a separate current-format project; old runtime code is not included.

Read the [quickstart](https://github.com/HaoYangJin/Big-Research/blob/v2.1.0/docs/quickstart.md), [methods](https://github.com/HaoYangJin/Big-Research/blob/v2.1.0/docs/methods.md), [compatibility](https://github.com/HaoYangJin/Big-Research/blob/v2.1.0/docs/compatibility.md) and [historical-data guidance](https://github.com/HaoYangJin/Big-Research/blob/v2.1.0/docs/history.md).

Limitations: MCP requires local execution and uv/Python; interactive rendering depends on client support. No model, scholarly database subscription, clinical validation or expert-calibrated scoring is bundled. File integrity checks do not certify scientific claims. Official plugin-directory review is separate from this GitHub release.
