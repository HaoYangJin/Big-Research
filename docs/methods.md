# 研究方法与评议 / Methods and review

研究领域不是方法选择器。历史研究可以使用定量材料，医学可以进行质性访谈，计算机论文也可以只有理论证明。先确认问题、范式、贡献和材料，再选择方法。

| 方法模块 | 重点检查 |
| --- | --- |
| 定量与实验 | 设计、独立性、测量、泄漏、对照、误差与复现 |
| 质性 | 范式一致性、采样理由、同意与保密、分析过程、反身性和反例 |
| 解释与人文 | 来源与语境、版本与翻译、解释路径、竞争读法、论证与范围 |
| 形式化与理论 | 定义、假设、推导、边界、反例、理论与计算的区别 |
| 文献综合 | 综述类型、覆盖、筛选、来源评估、综合方法和偏差 |
| 混合方法 | 组合理由、各部分质量、整合过程、矛盾发现和综合结论 |

## 三层评议

1. 通用研究质量：问题价值、学术背景、方法适配、论据与论证、替代解释、表达与伦理。
2. 方法检查：依研究范式加载，不把统计显著性或实验可证伪性作为普遍门槛。
3. 领域或投稿标准：在适用时叠加 ICLR、NeurIPS、ACM 产物评估、APA JARS、医学报告规范或人文期刊指南。

报告规范检查“是否清楚报告了必要信息”；偏倚、证据确定性和科学有效性需要相应的独立判断。内置规范资料是有边界的摘要或选择指引，不冒充完整官方清单。

没有正式量表时，按问题、范式、贡献类型和读者建立透明的工作标准，说明出处与理由。每项给出充分、需改进、无法判断或不适用，并附证据位置、解释与修改路径。材料缺失不是已经证明的方法错误，解释分歧也不自动意味着一方错误。

## 评分的边界

我们参考 Stanford Agentic Reviewer 的来源检索与分维度反馈，但没有复现其模型、权重或校准。本插件没有经过验证的跨学科总分，不输出录用概率，也不宣称与专家等效。记录每次评议的实际阅读范围、抽样、置信度及限制，比一个没有依据的精确分数更有用。

English: review combines a declared general rubric, method-specific reasoning and optional sourced overlays. No venue is required. The output provides criterion-level judgments, evidence positions, coverage, confidence and actionable revisions. Reporting guidance is not a validity scale.
